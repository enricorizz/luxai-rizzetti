# AgentImm AI — payload PWA v3.0.0

Questa cartella contiene esclusivamente i nove blocchi testuali compressi del frontend statico AgentImm AI. Non contiene dati di clienti, immobili reali, password, token o chiavi API.

La build Vercel di produzione usa gli asset del commit immutabile:

`3977138b850b89f4245378731a8be78501a9ae3f`

I blocchi `p00.txt`–`p08.txt`, concatenati, decodificati Base64 e decompressi GZIP, producono il payload JSON con CSS e JavaScript della PWA. Il codice sorgente leggibile e i test sono conservati nel pacchetto di rilascio AgentImm AI Rizzetti v3.0.0.
